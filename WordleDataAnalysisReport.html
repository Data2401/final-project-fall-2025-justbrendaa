Introduction

Wordle is a daily word puzzle in which players attempt to guess a five-letter English word within six attempts. Each guess provides structured feedback based on letter accuracy and placement. Although the game appears simple, its dataset of solutions contains linguistic patterns that can be statistically analyzed.

The goal of this project is to understand the structure of the official Wordle answer list. By examining letter usage, positional behavior, bigram patterns, repeated-letter distributions, and relationships between word frequency and Scrabble score, this project answers the broader question:

Does Wordle follow predictable linguistic patterns, and how can these patterns improve player strategy?

This problem is meaningful because understanding these trends allows players to make more informed guesses and reveals how puzzle designers curate word lists.

Questions to Answer

This analysis focuses on the following core questions:

  1. Which letters appear more frequently in Wordle solutions?
  2. Which letters appear more frequently in Wordle solutions by position?
  3. Which letter pairs (bigrams) appear most often in Wordle solutions?
  4. How does the bigram frequency change depending on where they appear in the word?
  5. Do repeated letter Wordle answers follow seasonal or monthly patterns across different years?
  6. Is there a relationship between a word’s frequency in English and its Scrabble point value?

Data Analysis

Question 1 - Which letters appear more frequently in Wordle solutions?

This section analyzes the overall distribution of letters across all Wordle solutions. Each answer contains five letters, but their frequencies vary widely. Identifying these differences helps show which letters Wordle relies on most often and establishes a baseline for understanding more detailed patterns in later sections.


Step 1: Extracting and Counting Letter Frequencies

The code below retrieves the letter in each of the five positions (P1–P5), reshapes them into a long format, and counts how often each letter appears. Letters are also labeled as vowels and consonants to support interpretation of the results.


# pulling letters, counts, and type
letter_frequency <- wordle_data %>% 
  select(P1, P2, P3, P4, P5) %>% 
  pivot_longer(cols = c(P1, P2, P3, P4, P5), names_to = "Position", values_to = "Letter") %>% 
  group_by(Letter) %>% 
  summarise(Counts = n()) %>% 
  arrange(-Counts) %>% 
  mutate(Type = ifelse(Letter %in% c("A","E","I","O","U"), "Vowel", "Consonant"))

Question 2 - Which letters appear more frequently in Wordle solutions by position?

This section examines whether certain letters are more common in specific positions within Wordle solutions. English words often follow predictable structural patterns, such as frequent starting consonants (e.g., S, C, T) and common ending letters (e.g., E, Y). Analyzing positional frequency allows us to see how closely Wordle solutions follow these linguistic tendencies. Understanding these patterns can also improve strategic guessing by highlighting which letters are more informative depending on their position in the word.


Step 1: Identifying the most frequent letters in each position

The following code calculates how often each letter appears in positions P1 through P5. By reshaping the dataset and summarizing counts within each position, we can identify the top-position letters and compare trends across positions.

Fun Fact!

One observation I have made while playing Wordle is that five-letter solutions ending in the letter “S” are relatively uncommon, especially when compared to how frequently plurals occur in everyday English. A typical plural formed by adding “S” to a four-letter base word appears far less often in the official Wordle answer list.

Examples of these plural formations include:

CART → CARTS

BOOK → BOOKS

CARD → CARDS

Based on the positional data, only 23 out of more than 1,600 Wordle solutions end with S. This suggests that simple plural forms are not commonly selected as answers. This observation refers specifically to plural endings and is not related to past-tense endings such as “ED”.

For strategy purposes, this means that when the last letter is unknown, guessing a word ending in S is usually not a productive choice, especially compared to endings like E, Y, or T, which are far more common.

Question 3 – Which letter pairs (bigrams) appear most often in Wordle solutions?

English words rely heavily on recurring two-letter sequences, and many of these patterns appear in Wordle as well. A bigram is simply a pair of consecutive letters. Each Wordle answer contains four bigrams: letters (1–2), (2–3), (3–4), and (4–5). By counting how often each bigram appears across all solutions, we can identify which pairs Wordle uses most frequently.

The table below lists the ten most common bigrams across the entire dataset. Many of these pairs reflect standard English structure, such as common prefixes, vowel-consonant transitions, or typical word endings.

# pulling bigrams
bigrams <- wordle_data %>% 
  mutate (B1 = paste0(P1, P2),  # paste0 no separator by default
          B2 = paste0(P2, P3),
          B3 = paste0(P3, P4),
          B4 = paste0(P4, P5)) %>% 
  select(B1, B2, B3, B4) %>% 
  pivot_longer(cols = everything(), names_to = "Position", values_to = "Bigram") %>% # names_to = col name to create from specified cols before, values_to = new column to create from values in each cell.
  group_by(Bigram) %>% 
  summarise(Counts = n()) %>%
